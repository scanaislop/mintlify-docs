aislop 是一款开源 CLI，专门为 AI 生成的代码把好质量关。在仓库里运行它，你会得到一个 0 到 100 的分数、精确到文件和行号的修复清单，以及一个可以在 CI 中强制执行的退出码。

scanaislop.com 是围绕这个 CLI 构建的托管平台，提供徽章、公开扫描和团队门禁。本文档介绍的是 CLI。

```bash
npx aislop@latest scan
```

```
Score  87 / 100  Healthy

⚠  ai-slop/narrative-comment     src/auth/login.ts:14
⚠  ai-slop/unused-import         src/services/users.ts:3
⚠  code-quality/function-too-long src/commands/fix-render.ts:14

0 errors · 6 warnings · 4 fixable
```

无需任何配置。同样的代码，永远得到同样的分数。运行路径中没有任何语言模型：aislop 依靠正则表达式、AST 分析和标准开源工具完成检查。

## 能发现什么

AI 编程助手（Claude Code、Cursor、Codex、OpenCode、Gemini CLI）写出的代码常常能通过测试和 lint，却留下不少残渣：复述代码的叙述式注释、被吞掉的异常、`as any` 强转、凭空捏造的 import、死代码、TODO 占位和过长的函数。aislop 收录了 50 多种这类模式，并按权重计分，让安全问题和高置信度缺陷比机械性清理扣分更重。

## 支持 11 种语言

| 语言 | Target |
|---|---|
| TypeScript | `typescript` |
| JavaScript | `javascript` |
| Expo / React Native | `expo` |
| Python | `python` |
| Go | `go` |
| Rust | `rust` |
| Ruby | `ruby` |
| PHP | `php` |
| C# | `csharp` |
| Java | `java` |
| C/C++ | `cpp` |

即使缺少可选的系统工具，内置检查也照常运行。如果一个仓库主要由不支持的语言（Swift、Kotlin）构成，aislop 不会拿零星几个文件来打分，而是暂不给分并报告 `scoreable: false`。

## 为什么能放心用在 CI 中

- **确定性。** 运行时不调用 LLM，同一份代码树永远得到同一个分数。
- **快速。** 各引擎并行运行，大多数项目的扫描耗时远低于一秒。
- **零配置上手。** `npx aislop@latest scan` 在任何受支持的仓库中都能直接运行。需要阈值、规则覆盖或架构规则时，再添加 `.aislop/config.yml`。
- **完整的修复路径。** `aislop fix` 负责机械性清理。`aislop agent` 会启动本地的 Codex、Claude Code 或 OpenCode 会话，由 aislop 负责打分和验证。

当前 CLI 版本：**v0.19.1**，采用 MIT 许可证。

## 交给你的编程助手

把下面这段话粘贴到 Claude Code、Cursor、Codex 或其他编程助手中，它会安装 aislop skill、hooks 和 `AGENTS.md` 规范。

```text
Read https://docs.scanaislop.com/agents and set up aislop for this repo: install the skill, install hooks, write AGENTS.md, then scan.
```

或者直接运行：

```bash
npx skills add scanaislop/skills
npx aislop@latest hook install
```

完整的提示词、AGENTS.md 模板和相关 URL：[For agents（英文）](/agents)。
