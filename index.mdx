Run it on a repo and get a score from 0 to 100, a file-and-line fix list, and a CI exit code you can enforce. These docs cover the open-source CLI; [scanaislop.com](https://scanaislop.com) is the hosted platform around it (badges, public scans, team gates).

```bash Run it
npx aislop@latest scan
```

```text Output

⚠  ai-slop/unused-import          src/services/users.ts:3
⚠  code-quality/function-too-long src/commands/fix-render.ts:14

0 errors · 6 warnings · 4 fixable
```

No config required. Same code in, same score out. There is no language model in the runtime path: aislop uses regex, AST analysis, and standard open-source tooling.

## What it catches

AI coding agents (Claude Code, Cursor, Codex, OpenCode, Gemini CLI) often produce code that passes tests and lint, then leaves residue: narrative comments, swallowed exceptions, `as any` casts, hallucinated imports, dead code, TODO stubs, oversized functions. aislop encodes 50+ of those patterns and weights them so security and high-confidence defects hit harder than mechanical cleanup.

## Six engines

Every scan runs six engines in parallel. Architecture is opt-in.

## 11 language targets

| Language | Target | Language | Target |
|---|---|---|---|
| TypeScript | `typescript` | Ruby | `ruby` |
| JavaScript | `javascript` | PHP | `php` |
| Expo / React Native | `expo` | Java | `java` |
| Python | `python` | C# | `csharp` |
| Go | `go` | C/C++ | `cpp` |
| Rust | `rust` | | |

Built-in checks still run when optional system tools are missing. If a repository is mostly an unsupported language (Swift, Kotlin), aislop withholds the score and reports `scoreable: false` instead of scoring a handful of incidental files.

## Give this to your agent

Paste this into Claude Code, Cursor, Codex, or any other coding agent. It installs the aislop skill, hooks, and `AGENTS.md` standard.

```text
Read https://docs.scanaislop.com/agents and set up aislop for this repo: install the skill, install hooks, write AGENTS.md, then scan.
```

Or run:

```bash
npx skills add scanaislop/skills
npx aislop@latest hook install
```

Full copy-paste prompt, AGENTS.md template, and URLs: [For agents](/agents).
