# aislop docs

Public documentation for the [aislop](https://github.com/scanaislop/aislop) CLI, published at [docs.scanaislop.com](https://docs.scanaislop.com).

Mintlify MDX plus `docs.json`. Command, flag, scoring, language, and CI examples must match the CLI in `scanaislop/aislop`.

aislop is the CLI. [scanaislop.com](https://scanaislop.com) is the hosted product around it.

## Preview

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Publish

The Mintlify GitHub app deploys from the default branch after merge.

## Brand

- Site name: `aislop`
- Logo: `/assets/logo-light.svg` and `/assets/logo-dark.svg`
- Favicon: `/assets/favicon.svg` (same mark as scanaislop.com)
- No generated hero illustrations

If a page 404s locally, run from the directory that contains `docs.json`.
