aislop ist die Open-Source-CLI, die als Quality Gate für KI-generierten Code dient. Du lässt sie über ein Repository laufen und bekommst einen Score von 0 bis 100, eine Liste mit Datei und Zeile für jede Korrektur und einen Exit-Code, den du in CI durchsetzen kannst.

scanaislop.com ist die gehostete Plattform rund um diese CLI: Badges, öffentliche Scans und Team-Gates. Diese Dokumentation behandelt die CLI.

```bash
npx aislop@latest scan
```

```
Score  87 / 100  Healthy

⚠  ai-slop/narrative-comment     src/auth/login.ts:14
⚠  ai-slop/unused-import         src/services/users.ts:3
⚠  code-quality/function-too-long src/commands/fix-render.ts:14

0 errors · 6 warnings · 4 fixable
```

Keine Konfiguration nötig. Gleicher Code ergibt immer den gleichen Score. Im Ausführungspfad steckt kein Sprachmodell: aislop arbeitet mit regulären Ausdrücken, AST-Analyse und etablierten Open-Source-Tools.

## Was aislop findet

KI-Coding-Agents (Claude Code, Cursor, Codex, OpenCode, Gemini CLI) erzeugen oft Code, der Tests und Linter besteht und trotzdem Rückstände hinterlässt: erzählende Kommentare, verschluckte Exceptions, `as any`-Casts, halluzinierte Imports, toten Code, TODO-Stubs und überlange Funktionen. aislop kennt über 50 solcher Muster und gewichtet sie so, dass Sicherheitsprobleme und eindeutige Defekte stärker zählen als mechanisches Aufräumen.

Die eingebauten Prüfungen laufen auch dann, wenn optionale Systemtools fehlen. Besteht ein Repository überwiegend aus einer nicht unterstützten Sprache (Swift, Kotlin, Java), hält aislop den Score zurück und meldet `scoreable: false`, statt ein paar zufällige Dateien zu bewerten.

## Warum es in CI sicher ist

- **Deterministisch.** Kein LLM zur Laufzeit. Derselbe Stand ergibt immer denselben Score.
- **Schnell.** Die Engines laufen parallel. Die meisten Projekte sind in deutlich unter einer Sekunde gescannt.
- **Ohne Konfiguration startklar.** `npx aislop@latest scan` funktioniert in jedem unterstützten Repository. Leg `.aislop/config.yml` an, sobald du Schwellenwerte, Regel-Overrides oder Architekturregeln brauchst.
- **Weg zur Reparatur.** `aislop fix` übernimmt das mechanische Aufräumen. `aislop agent` startet eine lokale Codex-, Claude-Code- oder OpenCode-Session, in der aislop Bewertung und Verifikation übernimmt.

Aktuelle CLI: **v0.18.1**. MIT-Lizenz.

## Für deinen Agent

Füge das in Claude Code, Cursor, Codex oder einen anderen Coding-Agent ein. Es installiert den aislop-Skill, die Hooks und den `AGENTS.md`-Standard.

```text
Read https://docs.scanaislop.com/agents and set up aislop for this repo: install the skill, install hooks, write AGENTS.md, then scan.
```

Oder führe aus:

```bash
npx skills add scanaislop/skills
npx aislop@latest hook install
```

Vollständiger Prompt, AGENTS.md-Vorlage und URLs (auf Englisch): [For agents](/agents).
